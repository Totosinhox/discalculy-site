# Discalculy — site educativo
Site responsivo em HTML, CSS e JavaScript puro. Não precisa instalar bibliotecas.

## Como abrir
1. Extraia o ZIP.
2. Abra a pasta `discalculy-site`.
3. Abra `index.html` no navegador.

## Funcionalidades
- Navegação por seções e menu adaptado a celular.
- Três minijogos: contas rápidas, comparação de números e sequência.
- Cinco rodadas por jogo, pontuação, feedback e reinício.
- Conteúdo informativo, dicas, referências externas e aviso de que o site não diagnostica discalculia.
- Funciona localmente; não há cadastro nem banco de dados.

## Editar no VS Code
- `index.html`: textos e estrutura.
- `styles.css`: cores, layout e responsividade.
- `script.js`: lógica dos minijogos.

## Sobre o protótipo Figma
O link enviado não pôde ser visualizado diretamente neste ambiente. Esta versão usa uma identidade visual própria, com roxo, coral, amarelo e menta e mascote ilustrado em CSS. Para copiar fielmente o protótipo, envie capturas de tela ou exporte o logo/mascote do Figma.
